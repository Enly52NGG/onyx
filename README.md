# ONYX RP — Официальный правовой портал

Тёмный премиальный портал правил, кодексов и регламентов проекта ONYX RP.

## Требования

- Node.js 18+ (рекомендуется 20 LTS)
- npm (идёт вместе с Node.js)

Скачать Node.js: https://nodejs.org/

## Запуск на Windows / macOS / Linux

1. Распакуйте архив `onyx-legal-portal.zip`
2. Откройте терминал (PowerShell / cmd / Terminal) в папке `onyx-legal`
3. Установите зависимости:

```bash
npm install
```

4. Запустите сайт:

```bash
npm run dev
```

5. Откройте в браузере: **http://localhost:3000**

Остановка: `Ctrl + C` в терминале.

## Сборка для продакшена

```bash
npm run build
npm start
```

## Структура

```
onyx-legal/
├── public/
│   ├── logo.png          # Логотип ONYX
│   └── docs/             # Исходные тексты документов
├── src/
│   ├── app/              # Страницы (App Router)
│   ├── components/       # UI-компоненты
│   ├── data/             # Документы и категории
│   └── lib/              # Типы
├── package.json
└── ...
```

## Возможности

- Поиск по статьям и тексту
- Каталог документов с фильтрами
- Якорные ссылки на статьи
- Копирование ссылок и печать
- Адаптивный дизайн (телефон / планшет / ПК)
- Тёмная тема (чёрный + графит + золотой акцент)

## Примечание

Все документы имеют статус «требует проверки». Формулировки сохранены из исходных файлов проекта.
